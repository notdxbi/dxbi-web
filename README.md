# dx.bi web

dx.bi's own copy of [Stremio's web app](https://github.com/Stremio/stremio-web), built unchanged from a pinned
release and published at https://notdxbi.github.io/dxbi-web/. The dx.bi apps will load this instead of
web.stremio.com, so a change on Stremio's site can't break them before it has been tested.

- Source: Stremio/stremio-web at the tag in `.github/workflows/build.yml` (`STREMIO_WEB_REF`).
